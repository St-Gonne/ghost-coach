### Acceptance Tests

1. Sample day produces valid primary, backup, and minimum-win plan
2. Re-running planning for the same date is idempotent
3. Invalid candidates are rejected with visible reasons
4. Outdoor activity rejected when weather is OUTDOOR_BLOCKED
5. Floor physio rejected at airport location
6. Plan state transitions follow the defined machine
7. Nudge policy respects quiet hours and daily cap
8. LLM invalid ID falls back to deterministic selection
